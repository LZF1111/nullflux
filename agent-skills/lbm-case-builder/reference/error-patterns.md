# LBM 常见问题与修法 (error patterns)

## 失稳 / 发散（最常见）
| 症状 | 根因 | 修法 |
| --- | --- | --- |
| ρ 或 u 出现 NaN/Inf | u_lb 过大 或 τ 太接近 0.5 | 降 u_lb(≤0.1) / 加分辨率使 τ 远离 0.5 / 换 MRT·Regularized |
| 高 Re 一跑就炸 | BGK 在高 Re 不稳 | 换 MRT/Cumulant/Regularized；或加分辨率 |
| 局部棋盘格振荡 | 数值噪声、τ 过小 | Regularized 碰撞 / MRT 调高阶松弛率 |
| 密度整体漂移 | 边界不守恒质量 | 用守恒 BC（Zou-He/非平衡外推），检查入出口质量平衡 |

- 稳定性经验：$u_{lb}\lesssim 0.1$ 且 $\tau>0.5$（BGK 实用 τ≳0.51）。真高 Re 靠**加分辨率**（增大 $L_{lb}$
  从而增大 $\nu_{lb}$、抬高 τ）或换高阶碰撞，而不是硬调 τ。

## 边界问题
| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 壁面渗漏/穿墙 | opposite 表错 或 只反弹了部分方向 | 核对 opposite；bounce-back 覆盖所有指向域内的 f_i |
| 壁面速度不为 0 | 用了全程 bounce-back 但期望半格 | 改半程 bounce-back（二阶，壁在半格） |
| 入口速度对不上 | Zou-He 分量抄错边 | 照官方类按具体边(左/右/上/下)写；或用非平衡外推(通用) |
| 顶盖驱动方腔角点异常 | 角点分布双重约束 | 角点特判（先速度 BC 再补角点 f） |

## 单位 / 换算错
| 症状 | 根因 | 修法 |
| --- | --- | --- |
| Re 与预期差几个数量级 | 把物理 SI 直接当格子量 | 严格无量纲化：定 u_lb→ν_lb=u_lb·L_lb/Re→τ=3ν_lb+0.5 |
| 时间/力换算错 | 漏了 Δt、Δx 换算 | 记录换算表：Δx=L_phys/N, Δt 由 u_lb=u_phys·Δt/Δx |

## 收敛
- 稳态残差不降：可能已达定常但阈值太严；或分辨率不足有物理振荡（如绕流脱涡本就是瞬态）。
- 绕流该是瞬态却当稳态：Re 超临界会周期脱涡，别求稳态残差，看斯特劳哈尔数。

## 交付前静态自检清单
- [ ] $\sum_i w_i = 1$
- [ ] 速度集对称、opposite 表与索引一致
- [ ] τ > 0.5，u_lb < 0.1
- [ ] feq 用了正确 $c_s^2=1/3$（3/4.5/1.5 系数）
- [ ] bounce-back 覆盖全部入射方向；运动壁加了动量项
- [ ] 数组含全部 Q 方向；双缓冲无覆盖
- [ ] 输出前做 NaN 检查
