# CFDriver4MTO 产品与验收合同

## 定位

以可信 CFD 执行、长时任务恢复和物理评估为底座，在其上增加未知量反演与工况/几何搜索。不是通过调提示词保证任意论文吻合，也不把代理模型优化等同于真实反应器设计。

三类产品目标：论文复现、未知量补全、反应器设计。用户直接描述目标并提交论文、算例或数据，不再先选择只有提示词差异的工作流模式。系统组织工具，用户掌握约束、证据与执行权限。

## 不可绕过的设计约束

- 需求合同区分论文明确值、读图值、工程假设和优化变量；记录单位、来源、边界及批准人。
- 原文明确值不得为了提高拟合分数而改变。未知分布器可生成等效候选，不宣称唯一恢复真实几何。
- 分开报告论文 CFD 复现误差、实验预测误差、数值误差和观测不确定性。
- 执行完成、数值合格、物理有效、外部泛化分层记录；任何一层缺证据不自动升级。
- 硬约束失败无有效奖励。固定开发验收不等于封存盲测，最终盲测不能反复反馈给搜索器。
- 源项、相分率、边界流率、碳与催化剂收支必须独立核算。残差收敛或云图外观不能代替物理验证。
- 多核单算例与多候选并发分别计量，统一 CPU/内存配额、任务身份、超时、取消和幂等登记。
- 搜索与经验库不能修改验收代码、数据划分或工程安全约束。评估器更改需要新版本及人工批准。

## 交付阶段与退出门

### P0 可靠底座

断网恢复、鉴权错误停止、人工取消、重启接管、待审批不越权、重复工具不重放，均有自动回归。故障注入验证服务器/工作进程中断后无静默遗失或重复登记；长时作业有心跳、失败原因与下次恢复时间。

自动任务执行所有者现在独立于浏览器连接存活，关闭页面只解除订阅，重连控制路由原所有者；人工审批和显式停止的语义不变。任务完成同步旁观窗口，避免上下文压缩后旧历史覆盖；浏览器连接不再自动发送 set_auto，权限由服务端持久任务状态驱动，只有用户切换才修改。

回归命令：`npm run test:foundation`、`npm run test:integration`；Python Optuna 回归为 `python -m unittest discover -s test -p test_opt_driver.py -v`。原跨 VM 比较夹具已修正，不降低内容和不重放工具断言。真实断连测试同时覆盖自动模式继续、任务隔离、实时输出、引导/停止、人工审批取消持久化。

底座与界面精简回归由固定测试命令维护，整服务 integration 4/4；Python 18 通过/1 项 Windows 符号链接权限跳过。浏览器实测人工模式断线重连不改变权限；1440px/390px 无横向溢出，状态/文件/结果标签可切换，草稿保留。这些是本地源码验证，未部署远端或运行新的真实 CFD。

独立整服务恢复实验约 30 秒，确认已执行工具仅一次、无新用户指令、恢复计划在重启后保持。模拟 LLM 与小型进程，不是实际供应商 SLA、连续数日运行保证或真实 CFD 物理精度验收。更长时间的故障注入与负载压测仍是发布门槛。

### P1 可重放 MTO 基准

冻结当前 pilot 算例及论文观测。清洁环境重建几何、网格、模型和动态库；追踪内容哈希与求解器版本。验证重力轴、反应区、漏料、进料组成及单位；冷热态分别验收。最终时刻已算完并不等于最终报告已验收。

至少三档网格和时间步敏感性、统计独立性、多初值与慢变量检查。所有阈值根据论文误差和工程目标事先批准；不能在本文件凭空设置通用保证值。

### P2 未知量补全

先做已知真值的合成反演，再用论文数据。先灵敏度/可辨识性筛选，再搜索受制造约束的分布器族。拟合数据与开发验收数据分离，最终封存工况独立测评；不唯一时输出候选族和区间。

### P3 有界并行与成本控制

资源队列持久化租约，支持多个小候选并行、完整算例单独配置。至少完成多 worker、多 trial 的中断压测，确认无超配、串目录、重复登记和遗留失控进程。代理/冷态/粗网格筛选后，少数候选晋级高保真，不盲跑完整 CFD。

### P4 反应器优化设计

从处理量、进料、产品目标、能耗和制造约束生成候选。输出几何、工况、约束余量、性能区间、数值/模型不确定性与 Pareto 权衡。最优候选必须经高保真复算和独立工况验收，不将单一标量最优包装为工程最优。

### P5 可信 RSI

固定模型、任务、预算和评估器，对比无记忆、经验复用与 RSI 的成功率、物理误差、耗时和成本。改进需跨工况和未见几何成立。失败轨迹保留作诊断，不作为已验证成功技能或 SFT 标签。

## 工作台

设计原则：减少用户必须理解的模块，不减少可追溯证据和安全边界。已删除主工作台的装饰观察员、仅改变提示的工作流选择器、厂商专用及本地重复 API 表单、11 个重复求解器向导和长提示模板。独立展示页面仍引用的资源不删除，避免误伤。

模型连接统一为 URL、模型 ID、API Key，支持 OpenAI Chat Completions 兼容接口及本地端点；Copilot 另用授权入口。独立视觉设置默认继承且按需展开，跨域不转发主密钥。既有配置不被迁移或覆盖。非 OpenAI 协议需外部适配，不能宣称任意原生协议通用。

运行监测自动选中当前任务唯一作业，多个作业不猜测，明确选择不被覆盖。刷新和快照配置位于监测详情，不占首屏；附件、图片证据、残差、验证、技能记录、审批与停止保留。

默认显示宽任务区与右侧上下文，状态/文件/结果按标签切换，不首屏展开空编辑器。使用中性浅灰、白色内容和蓝色操作、统一系统字体与留白。Auto 权限保留主栏，模型、设置、发送与停止始终可达。高级工具和领域面板保留在菜单，旧手动布局可恢复。不以隐藏状态掩盖失败或不确定性。

本地入口为 /app；生产部署前必须完成浏览器及恢复回归。详细候选协议见 CFD_TRIAL_PIPELINE.md。
