# 任务：磁控溅射粉体镀膜振动托盘 —— DEM 设计（振动波形 + 托盘结构 + 参数验证）

## 背景与已知条件
- 托盘：直径 300 mm，深 20 mm，圆形。
- 颗粒：200 g，直径 100 µm（按 ±10% 均匀分布），密度 10000 kg/m³，球形。
- 托盘底部施加振动，让颗粒在托盘里运动，使磁控溅射镀膜更均匀（溅射只镀到最上层露出的颗粒表面）。
- 目标：通过 DEM 模拟颗粒在托盘内的运动，从振动波形设计、托盘结构改造、参数验证三方面给出托盘设备设计。

## 要做的（按顺序，每阶段用 run_stage_start / run_stage_done 记录）
1. **量级估算**（写进 MANIFEST.md）：颗粒总数、床层厚度、Γ 与振幅换算、接触时间与时间步、整盘真实粒径的计算量（说明为什么不可行），确定两级模型方案（A 级真实粒径周期小块；B 级粗粒化整盘）。
2. **基准**：在 b1 之外补齐 (a) 静止沉降（颗粒数守恒、最大重叠 < 1% d、床层高度与估算一致），(b) 竖直振动 Γ 扫描 0.8–4（60 Hz），看起跳阈值和流化，与文献定性对比，(c) 时间步减半 + 杨氏模量 ×4 的敏感性。
3. **振动波形设计（A 级）**：至少比较 竖直正弦、水平正弦、椭圆（竖直+水平，相位差 0/45/90/135/180°）、加二次谐波的非对称竖直波形；频率 30–120 Hz。每个工况振动 ≥ 0.3 s 物理时间（先沉降一次 write_restart，各工况从 restart 起步）。
   指标：表面轮换频率、颗粒间曝光剂量 CV 及其随时间衰减指数、颗粒自转角速度（决定单颗粒各向均匀）、碰撞/冲击速度 50/99 分位、最大抛起高度（必须远小于 20 mm）、净输运速度。
4. **托盘结构（B 级粗粒化整盘）**：粗粒化倍数 4–5，先在一个重叠工况上与 A 级对比床层膨胀与表层速度（误差 < 10% 才可用）。比较：平底、侧壁底部圆角、中心锥、4–8 条径向/螺旋导流筋。用 STL 写几何。指标：死区面积比例、径向混合时间、颗粒在各半径的停留时间分布。
5. **镀膜均匀性评估与外推**：用 dump 后处理（曝光遮挡模型），把 CV 外推到实际溅射时长（如 1 h）。
6. **参数验证**：对推荐方案做 摩擦 ±30%、恢复系数 ±0.1、粒径分布宽度、粗粒化倍数 的敏感性。
7. **交付**：`/home/user/vibtray/REPORT.md`（推荐振动波形与参数窗口、推荐托盘结构与尺寸、验证表、局限）+ 关键图（PNG）。
