## 1. 核心问题与论点

**问题**：只用一个极低维、离散的执行器（底部 3 个分区的气量开关），能否把成千上万个悬浮颗粒组成的“颗粒群”主动聚集到反应器内指定区域？

**论点**（三层）：
1. **可控性边界**：中性浮力颗粒群不可聚集。液相近似不可压，颗粒群在相空间的面积守恒，任何流动操控只能拉伸、折叠，不能压缩。离线和 CFD 结果都显示：盒内比例始终等于盒子的面积占比。
2. **沉降打开可控性**：颗粒有沉降速度 w_s 后，颗粒速度场 u_l − w_s·e_y 不再无散，出现“漏斗”。下降流区的颗粒加速下沉，上升流区的颗粒被托住。漏斗的位置随气体模式切换而移动。
3. **聚集需要闭环**：固定模式反而让角落的颗粒比随机分布还少；最好的周期开环也只比面积占比高一点。基于颗粒群分布测量的反馈切换，能把盒内比例提高 3–4 倍，并且在模型失配时仍然有效。

**为什么不直观**：欠驱动（3 个开关输入对几千个自由度），控制量是分布而非点坐标，最优动作取决于颗粒群的当前分布（同一时刻往哪吹，取决于颗粒现在在哪），所以没有固定时间表能等效替代。

**应用指向**：浆态床催化剂回收/分级、结晶器晶体收集、微藻采收、颗粒按沉速分选。

## 2. 系统设置（与 CFD 一致）

| 项 | 值 |
|---|---|
| 塔体 | 准 2D，宽 0.30 m，液高 0.45 m，间隙 2 cm（2D 计算） |
| 执行器 | 底部 3 等分区，模式 L/C/R = 全部气量给某一区，总表观气速 1 cm/s |
| 求解器 | twoPhaseEulerFoam v2306（教程 RAS/bubbleColumn 设置），5 mm 网格 |
| 颗粒 | 一向耦合：v_p = u_l + (0, −w_s) + 随机游走（D = 2×10⁻⁴ m²/s），壁面反射 |
| 控制周期 | 0.5 s（CFD 停算、改边界、续算） |
| 失配被控对象 | 加 Tomiyama 升力 + Burns 湍流弥散 |

## 3. 控制框架

```
          ┌──────────────────────────────────────────────┐
   │  被控对象：CFD（或实物）         │
  模式 ──▶│  气体分区 → 液相流场 u_l(x,t) → 颗粒群 {x_i}   │──▶ 颗粒位置（全部或部分）
  L/C/R   └──────────────────────────────────────────────┘   │
    ▲         │
    │      ┌────────────────────────────────────────────┐     │
    └──────│ 控制器（每 0.5 s）     │◀───────────┘
    │ 1. 状态：颗粒群位置 + 流场估计 F̂（不测流场）  │
           │ 2. 预测：对每个候选模式，F̂ 按一阶滞后趋向该   │
    │    模式平均场（τ=2 s），推演颗粒 1.5 s│
    │ 3. 目标：盒内颗粒比例最大（+ 切换惩罚）       │
    │ 4. 执行第一个模式，滚动         │
           └────────────────────────────────────────────┘
```

**关键设计**：控制器内部模型只用静态工况的时均场和测得的阶跃响应时间常数，**与被控对象不同**（被控对象有瞬时大涡、有失配闭合）。所以闭环收益本身就是对 sim2real 的检验。

**对照组**：固定 L / C / R；周期 L↔R（0.5/1/2/4/8 s 半周期）；周期 L↔C、R↔C。离线评估中挑最好的周期开环作为对照。

## 4. 已有结果

### 4.1 静态与单颗粒（引子）
- 流型三态：贴左壁、贴右壁、居中（不稳定）。近对称配比双稳。
- 6 区入口、脉冲供气都没有新增稳定状态。
- 单颗粒闭环“过门”：13 组对比中闭环赢 12 组。但本质是“目标对应模式”，过于直观，不作为主线。

### 4.2 颗粒群离线测试（swarm_feas.py，录制流场拼接，4000 颗粒，3 种子）

| 沉速 | 目标 | 固定模式 | 最好周期开环 | 反馈 |
|---|---|---|---|---|
| 0 | 左下角（面积 7.5%） | 5.9–6.6% | 6.9% | 6.5% |
| 1 cm/s | 左下角 | 5.3–7.0% | 8.9% | 20% |
| 2 cm/s | 左下角 | 4.5–7.8% | 13% | 45.6% |
| 2 cm/s | 中心（11%） | 12–13% | 12% | 8.8% |

### 4.3 颗粒群 CFD 在线（swarm_live.py，2000 颗粒，30 s，单种子）

| 被控对象 | 沉速 | 固定 L | 周期 L↔R 2 s | 反馈 |
|---|---|---|---|---|
| 基线 | 2 cm/s | 约 7.4% | 10.3% | **32.4%**（30 s 末 35.6%，仍在上升） |
| 失配 | 2 cm/s | 约 8.5% | 10.2% | **23.9%**（30 s 末 28.8%） |
| 基线 | 1 cm/s | 约 6.8% | 8.5% | 10.6% |

结论：沉速 2 cm/s 时 CFD 在线结果确认了离线结论，失配下仍有约 2.3 倍开环。沉速 1 cm/s 时在线收益很小，比离线差，需要更长时间或更好的预测模型。

### 4.4 P1 统计结果（CFD 在线，沉速 2 cm/s，左下角，3 个种子 × 60 s，起始流场相位 t0 = 20/25/30 s）

| 控制 | 基线被控对象 | 失配被控对象 |
|---|---|---|
| 固定 L | 7.9 ± 0.2% | 7.9 ± 0.1% |
| 周期 L↔R 2 s | 10.6 ± 0.3% | 10.6 ± 0.3% |
| 最优周期开环 L→C→R 1 s（P2 离线选出） | 15.9 ± 1.1% | 14.6 ± 0.2% |
| **颗粒群反馈** | **38.2 ± 1.6%** | **37.8 ± 2.3%** |

数值为最后 5 s 盒内比例（面积占比 7.5%），± 为 3 个种子的标准差。反馈是最优开环的 2.4–2.6 倍，两个被控对象上的结果几乎一样。
图：rsi/bubble_column/fig_swarm/fig_live.png、fig_snap.png。

### 4.5 P2 可控性相图（离线代理，3 个种子 × 40 s，8 个目标区 × 7 个沉速，开环比较了 15 种固定/周期方案）

- 沉速 0：所有区域的盒内比例 ≈ 面积占比（顶部角除外，那里有一点自由面附近的停滞效应），与面积守恒一致。
- 底部两角：随沉速单调变得可控，到 4 cm/s 时反馈达到面积占比的 12 倍；反馈相对最优开环在 1–2 cm/s 区间收益最大（1.5–1.8 倍）。
- 底部中间：只在 3–4 cm/s 时反馈才明显超过开环。
- 中心（上升流区）：沉速越大越难，反馈甚至不如开环（0.6–0.8 倍），说明短视的预测控制在这里失效，对应 P3。
- 壁面中段、顶部角：几乎不可控（比例 ≤ 2 倍面积占比）。
图：rsi/bubble_column/fig_swarm/fig_phase.png。数据：phase_map.json（本地 %TEMP%/opencode）。

### 4.6 P3 降阶模型预测控制（结论：中心不可控不是预测模型的问题）

**降阶模型**（rom.py）：U.water 快照 17137 帧（37 个运行），POD 取 20 阶（97% 能量），每个气体模式拟合一个仿射映射 a(k+1) = A_m a(k) + c_m（岭回归，0.1 s 步长）。多步拟合会发散，弃用。
在留出的 8 个运行上，1.5 s 预测的流场误差：ROM 0.056 m/s，平均场+滞后 0.10–0.12 m/s，保持不变 0.089 m/s；1.5 s 后颗粒位置误差：ROM 5.3 cm，平均场+滞后 9.7–12.7 cm。
**状态估计**（swarm_rom.py 里的 KF）：只用 300 个颗粒 0.5 s 的位移更新 ROM 系数，估计误差 0.055–0.06 m/s（不测颗粒的开环 ROM 为 0.104）。50 个颗粒也够用。

**CFD 在线结果**（沉速 2 cm/s，3 个种子 × 60 s，盒内比例为最后 5 s）：

| 目标 | 控制器 | 基线 | 失配 |
|---|---|---|---|
| 中心（面积 11.2%） | 固定 C | 9.9 ± 0.2% | |
| | 平均场+滞后反馈 | 11.1 ± 0.6% | |
| | ROM + 颗粒 KF | 11.4 ± 0.5% | 10.4 ± 0.6% |
| | ROM + 真实流场（上限） | 11.4 ± 0.4% | |
| 左下角（面积 7.5%） | 平均场+滞后反馈（P1） | 38.2 ± 1.6% | 37.8 ± 2.3% |
| | ROM + 颗粒 KF | 27.5 ± 7.4% | |

离线代理上结果相同：中心 ROM 反馈 0.07–0.12，均不超过面积占比；左下角 ROM 反而低于平均场模型（2 cm/s：0.35 vs 0.49）。

**解释**：预测流场误差减半、状态知道得完全准确（oracle），中心比例仍然等于面积占比。所以中心不可控来自物理，不来自预测模型：中心是上升流区，沉降颗粒在其中的停留时间由上升流速（约 0.2 m/s，比沉速大一个量级）决定，任何模式切换都只能把颗粒送进来再带出去，无法建立“汇”。可聚集区域需要同时满足：沉速能抵消局部液速（低速区），并且能用模式切换让这个低速区与颗粒来流相遇。底部角落满足，中心和壁面中段不满足。
在角落任务上，ROM 控制器更短视（只追最近 1.5–3 s 的瞬时涡），反而不如平均场模型稳定，说明这个任务需要的是“慢变量”预测，而不是瞬时流场的精度。

**对论文的意义**：把“不可控”从控制器能力里剥离出来，成为可控性边界的证据之一；配合 P4 给出“局部液速 < 沉速的低速区”判据。

## 5. 待做计划（细化）

### P1 统计化（约 1 天机时）
- 沉速 2 cm/s，左下角：反馈 / 周期 / 固定 × 基线 / 失配 × 3 种子 × 60 s。
- 指标：盒内比例 φ(t)，达到 2 倍面积占比的时间，末段均值 ± 标准差。
- 验收：反馈在两种被控对象上都显著高于最好开环（3 种子均值差 > 2 倍标准差）。

### P2 可控性相图（约 2 天机时，主要用离线测试，挑点做 CFD 在线）
- 横轴：无量纲沉速 w_s / U_circ（U_circ 为循环速度，约 0.2 m/s）。
- 纵轴：目标区域（4 角、中心、左右壁带、顶部）。
- 色标：反馈增益 φ_fb / φ_best_open，以及 φ_fb / 面积占比。
- 预期：w_s = 0 处全部为 1（面积守恒），底部角落最先变得可控，上升流区（中心）不可控。

### P3 更好的预测模型
- 用全部 CFD 快照训练降阶模型：每模式 POD + DMD，或模式条件下的线性代理模型。
- 观察器：只用颗粒位置估计流场相位（类似数据同化）。
- 验收：中心目标或 1 cm/s 沉速的在线增益明显提高。

### P4 机理分析
- 统计反馈策略的切换节律（模式驻留时间分布、与颗粒群质心相位的关系）。
- 构造最简“漏斗模型”：两涡交替 + 沉降，给出可聚集的必要条件（如 w_s 与下降流速比的阈值）。
- 和 P2 相图对照验证。

### P5 sim2real 前置
- 3D 带前后壁工况（W3D 已在算）：确认三态在实际间隙下存在。
- 部分观测：控制器只看 10% 颗粒，或位置加 5 mm 噪声，看增益是否保持。
- 控制延迟：决策后延迟 0.2–0.5 s 再执行。

### P6 展示视频
- 左右并排：周期开环 vs 反馈，CFD 实算，几千个颗粒逐步被赶进角落；下方是 φ(t) 曲线。
- 基于 make_autopilot_video.py 改写，配色延续现有展示风格，全部用实测数据。

### P7 实物台架
- 3 区分隔气室 + 针头布气，质量流量计固定总流量，3 个电磁阀切换，Arduino 驱动。
- 颗粒：密度略大于水的有色小球（例如 PMMA，沉速 1–3 cm/s，可按粒径调）。
- 相机 + 背光，颜色阈值识别颗粒，PC 端运行同一控制器。
- 先测三态与切换时间，再测聚集。

### P8 论文
- 题目方向：*Herding particle swarms in a bubble column with a three-zone gas distributor: controllability limits and feedback*。
- 结构：引言 → 系统与方法 → 三态流型与切换响应 → 可控性边界（面积守恒，相图）→ 反馈聚集（CFD 在线、失配鲁棒）→ 机理 → 实验（若有）→ 结论。
- 目标期刊：Chemical Engineering Journal / AIChE J（有实验时），或 Physical Review Fluids（偏机理时）。

## 7. 风险

- 一向耦合颗粒模型：高浓度颗粒群会反过来影响流动，论文中需限定颗粒体积分数很低。
- 2D 与实物差异：前后壁摩擦可能削弱贴壁三态（P5 检查）。
- 单种子结果有随机性：P1 之前所有数字只能作为趋势。
- 沉速 1 cm/s 在线收益弱：可能限制适用颗粒范围，需要 P3 改善。
